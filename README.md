# SAO Launcher Android 13

Independent Android 13+ edge-swipe launcher prototype inspired by the interaction concept of classic game-style launchers.

## v0.1 goals
- Android overlay service
- Left-edge swipe trigger that avoids the notification shade
- Simple launcher menu
- GitHub Actions APK build

No original SAO Launcher proprietary code/assets or purchase checks are reused.

## Install
Download the debug APK from the latest successful GitHub Actions run, install it, grant **Display over other apps**, then press **Swipe Launcherを開始**.

Swipe from the translucent area at the middle-left edge toward the right.
